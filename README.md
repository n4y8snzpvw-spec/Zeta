# Zeta

Zeta is a lightweight AI starter project for experimentation, automation, and prompt-driven workflows.

## Features

- Python-based CLI
- Simple response generation scaffold
- Ready for extension into an AI assistant or automation service

## Quick start

```bash
python -m zeta
```

## Development

```bash
python -m pip install -e .
```
